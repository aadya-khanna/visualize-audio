-- version 0: 8/9/2026 --

Description:

Application with 2 implementations: macOS & web for live audio visuals in a cool manner

Features
- 2 apps macOS and web
- multiple visual display options (freq bars, 8 bit, curve)
- color mapping options (intensity, freq)
- for web: ability to select multiple audio channels and connectors for music (only spotify working)
- MacOS: no login needed, complete Mac native workflow that streams Swift coded audio engine and Mic input from system

Future
- adding more visual displays w. cool effects
    - splash / diff shapes on screen
    - 3D procedural effects
- mood mapping / bg theme selector / dynamic picker
- song album color mapping / related hues
