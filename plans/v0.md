-- version 0: 8/9/2026 --

Description:

Native macOS application for live audio visuals that react to system sound.

Features
- macOS app (Swift/SwiftUI) — sole target as of ADR 001
- multiple visual display options (freq bars, 8 bit, curve)
- color mapping options (intensity, freq)
- system audio via Core Audio process tap (no loopback device, no login)
- microphone input as alternate source
- automatic now-playing overlay via MediaRemote (Spotify, Music, any app)

Future
- adding more visual displays w. cool effects
  - splash / diff shapes on screen
  - 3D procedural effects
- mood mapping / bg theme selector / dynamic picker
- song album color mapping / related hues
